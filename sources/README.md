# Sources

Do not dump raw private emails here by default. Capture only the minimal excerpts or summaries needed to support decisions.

Source inventory starts in `docs/00-constraints-and-sources.md`.

When adding research, include:

- source title
- URL or local path
- date accessed
- relevant excerpt or paraphrase
- how it changes a product decision
- whether the claim is `[SOURCE]`, `[JAMES]`, or `[AI-INFERENCE]`
